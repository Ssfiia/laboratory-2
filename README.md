# Задание 1.2
## Человек
### Текст задачи
Создайте сущность Человек, которая описывается:
- Имя: строка
- Рост: целое число
Может возвращать текстовое представление вида «Name, рост: height», где Name и height это переменная с именем и ростом.
Необходимо создать и вывести на экран следующих людей:
- Человек с именем «Клеопатра» и ростом 152
- Человек с именем «Пушкин» и ростом 167
- Человек с именем «Владимир» и ростом 189

### Алгоритм решения
Создаётся класс "Person" с двумя полями: "name" (строка) и "height" (целое число).
В конструкторе эти поля инициализируются переданными значениями.
Метод "toString()" возвращает строку, склеенную из имени, текста «, рост: » и значения роста.
В меню можно посмотреть трёх человек из условия или создать нового — имя вводится как непустая строка, рост как положительное число.

# Задание 1.3
## Имена
### Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трёх параметров: Фамилия Имя Отчество (например «Иванов Иван Иванович»). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.
Необходимо создать следующие имена:
- Клеопатра
- Пушкин Александр Сергеевич
- Маяковский Владимир

### Алгоритм решения
Создаётся класс "Name" с тремя полями: "surname", "name", "patronymic".
В конструкторе каждое значение проходит через метод "normalize", который заменяет пустые строки на "null", чтобы не заданные параметры не участвовали в выводе.
Метод "toString()" последовательно добавляет в "StringBuilder" только те части, которые не равны "null", разделяя их пробелом.
В меню есть демонстрация трёх имён и ручной ввод: пустая строка означает, что параметр не задан.

# Задание 2.4
## Сотрудники и отделы
### Текст задачи
Создайте сущность Сотрудник: имя и отдел, в котором он работает. У отдела есть название и начальник (тоже сотрудник). Сотрудник выводится как «Имя работает в отделе Название, начальник которого Имя», а если он сам начальник — «Имя начальник отдела Название».
Нужно:
1. Создать Петрова, Козлова, Сидорова в отделе IT.
2. Сделать Козлова начальником IT.
3. Вывести всех трёх сотрудников.

### Алгоритм решения
Создаются два класса: "Department" (название и начальник) и "Employee" (имя и отдел).
В "Employee" есть метод "isHeadOfDepartment()", который проверяет, является ли сотрудник начальником своего отдела. От этого зависит текст в "toString()".
В меню при входе создаётся отдел IT и три сотрудника. 
Пункты меню: показать отдел и сотрудников, назначить Козлова начальником, вывести всех сотрудников.

# Задание 3.4
## Сотрудники и отделы
### Текст задачи
Измените решение задачи 2.4 так, чтобы имея ссылку на сотрудника, можно было узнать список всех сотрудников его отдела.

### Алгоритм решения
В "Department" добавляется список "employees" и методы:
- "addEmployee(Employee)" — добавляет сотрудника в отдел;
- "getEmployees()" — возвращает список сотрудников отдела.
В конструкторе "Employee" сотрудник сам добавляется в свой отдел: "department.addEmployee(this)".
В "Employee" добавляется метод "getColleagues()", который возвращает список сотрудников отдела.
В меню при входе создаётся отдел IT и три сотрудника, Козлов сразу назначается начальником. Пункты меню позволяют посмотреть список сотрудников через любого из трёх, добавить нового сотрудника и узнать количество сотрудников в отделе.

# Задание 4.5
## Создаем Имена
### Текст задачи
Измените сущность Имя из задачи 1.3. Новые требования включают:
- Имя можно создать указав только Личное имя
- Имя можно создать указав Личное имя и Фамилию.
- Имя можно создать указав все три параметра: Личное имя, Фамилию, Отчество.
Необходимо создать следующие имена:
1. Клеопатра
2. Александр Сергеевич Пушкин
3. Владимир Маяковский
4. Христофор Бонифатьевич (здесь Христофор это имя, а Бонифатьевич — фамилия)

### Алгоритм решения
В класс "Name" добавляются три конструктора:
- "Name(String firstName)" — только личное имя, вызывает полный конструктор с "null" для фамилии и отчества.
- "Name(String firstName, String surname)" — имя и фамилия, вызывает полный конструктор с "null" для отчества.
- "Name(String surname, String firstName, String patronymic)" — все три параметра.
Первые два вызывают третий, чтобы все поля заполнялись в одном месте.
В меню есть демонстрация четырёх имён и три пункта для ручного создания.

# Задание 5.1
## Пистолет стреляет
### Текст задачи
Создайте сущность Пистолет, которая описывается следующим образом:
- Имеет Количество патронов (целое число)
- Может быть создан с указанием начального количества патронов
- Может быть создан без указания начального количества патронов, в этом случае он изначально заряжен пятью патронами.
- Может Стрелять, что приводит к выводу на экран текста «Бах!» в том случае, если количество патронов больше нуля, иначе делает «Клац!». После каждого выстрела (когда вывелся «Бах!») количество патронов уменьшается на один.
Создайте пистолет с тремя патронами и выстрелите из него пять раз.

### Алгоритм решения
Создаётся класс "Gun" с полем "bullets" (целое число).
Конструктор "Gun(int bullets)" инициализирует поле переданным значением, но не меньше нуля (через "Math.max").
Конструктор "Gun()" вызывает конструктор с параметром, передавая 5.
Метод "shoot()" проверяет количество патронов: если больше нуля — выводит «Бах!» и уменьшает счётчик на единицу, иначе выводит «Клац!».
Метод "toString()" возвращает строку «Пистолет (патронов: N)».
В меню создаёься пистолет с 3 потронами и 5 выстрелами, 5 потронами и вводится количество выстрелов, а также ввод числа потронов и числа выстрелов.
